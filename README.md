## `04` — SELECTED DATA SCIENCE WORK

### 🧠 Customer Churn Prediction

An end-to-end machine learning project focused on identifying customers at risk of churn and improving the detection of potential churners.

#### Model Performance

| Metric            |     Result |
| :---------------- | ---------: |
| ROC-AUC           | **0.8465** |
| PR-AUC            | **0.6534** |
| Optimal Threshold |   **0.30** |
| Churn Recall      | **74.87%** |
| Churn Precision   | **55.16%** |
| Churn F1-Score    | **0.6353** |

**Explainability:** SHAP-based feature analysis
**Risk Analysis:** Low / Medium / High risk segmentation

`Python` `Pandas` `NumPy` `Scikit-learn` `SHAP` `Machine Learning`

→ **Repository:** [Customer Churn Prediction](https://github.com/Nipuni7/customer-churn-prediction)
