## 🧠 Customer Churn Prediction

An end-to-end machine learning project focused on identifying customers at risk of churn and improving detection of potential churners.

**Pipeline:** EDA → Feature Engineering → ML → Threshold Optimization → SHAP → Risk Segmentation

### 📊 MODEL PERFORMANCE

<div align="center">

<table>
<tr>

<td align="center">

### `0.8465`

ROC-AUC

</td>

<td align="center">

### `0.6534`

PR-AUC

</td>

<td align="center">

### `74.87%`

CHURN RECALL

</td>

<td align="center">

### `0.6353`

F1-SCORE

</td>

</tr>
</table>

</div>

| Metric | Result |
| :--- | ---: |
| ROC-AUC | **0.8465** |
| PR-AUC | **0.6534** |
| Optimal Threshold | **0.30** |
| Churn Recall | **74.87%** |
| Churn Precision | **55.16%** |
| Churn F1-Score | **0.6353** |
| False Negatives | **94** |
| True Positives | **280** |

### 🔎 MODEL INTELLIGENCE

**Churn Drivers**

`Fiber Optic` · `Monthly Charges` · `Electronic Check` · `Paperless Billing`

**Retention Signals**

`Tenure` · `Two-Year Contract` · `One-Year Contract` · `Online Security`

### 🎯 CUSTOMER RISK SEGMENTATION

| Risk Level | Customers | Actual Churn Rate |
| :--- | ---: | ---: |
| 🟢 Low Risk | 901 | **10.43%** |
| 🟡 Medium Risk | 296 | **46.96%** |
| 🔴 High Risk | 212 | **66.98%** |

### 💡 KEY RESULT

The optimized threshold of **0.30** increased churn recall to **74.87%**, detecting **280 of 374 churners**, while reducing false negatives to **94**.
